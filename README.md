## Why this repository | 为什么建立这个项目？

Foundation models are not just a list of model releases. Behind every capability are research questions, training recipes, evaluation choices, data pipelines, and engineering teams.

这里不是模型排行榜，也不是职位广告墙，而是一个**可追溯来源、持续修订的 AI 基座模型公开研究笔记库**。目标是回答三个问题：

1. **Technology** — 新技术到底解决了什么问题？技术路线有什么不同？
2. **Teams & roles** — 研发过程中需要哪些研究员与工程师？职责边界在哪里？
3. **Talent implications** — 技术方向的变化，可能怎样影响岗位能力要求？

本项目的内容以**公开论文、研究项目、官方技术报告**为依据，招聘与人才相关观点会特别注明“观察 / 推断”，不会将推断写成招聘事实。

## Research lens | 研究范围

**Core focus / 核心专注**
- **Large Language Models** — Foundation pre-training, data and compute scaling, model architecture, training/evaluation.
- **Multimodal Models** — Vision-language, video/audio-language, cross-modal data, multimodal foundation training.
- **Generative Models** — Image and video generation foundations; diffusion and transformer-based generation.

**Adjacent watchlist / 延伸关注**
- **Agent Applications** — Tool use, coding agents, agent evaluation and applications.
- **AI Infrastructure** — Distributed training, data infrastructure, inference and systems optimization.

*Agent 和 AI Infra 属于关联观察方向，不等同于本项目主要的基座训练研究范围。*

## How to read these notes | 阅读提示

- 论文中的**实验结果**只代表其公布的实验设置，不自动代表当前行业最优。
- **Pre-training、post-training、inference、application** 是不同技术阶段；具体岗位可能横跨多个阶段。
- 岗位画像是**技术工作内容的分析框架**，不是未经验证的团队内部招聘要求。
- 公开资料不代表对任何公司的内部信息、岗位或人才拥有授权。
